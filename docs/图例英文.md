## Figure 1: AI Novel Director Main Workflow Diagram 

The system begins with the project and setting database, combining it with the current chapter input to construct a chapter contract and beat plan. It then passes through pre-generation review, main text generation, post-generation review, and minimal revision to produce the chapter output.

The generated result enters a review session, where the user chooses to commit or discard it. Once committed, the system synchronously writes the chapter, version history, story state events, and I/O logs, and feeds the updated state back into subsequent chapter generation, forming a closed-loop creative framework for long-form serialization.

Setting extraction, polishing/modification, and chapter inspection operate as side workflows, sharing the same AI orchestration and governance mechanism.
